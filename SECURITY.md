# Security policy

C.O.N.D.R. is experimental software and is not intended for secure or
production use. Its kernel-mode shell and in-memory storage are not security
boundaries or durable storage.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.
Use the repository's **Report a vulnerability** option on GitHub's Security
tab when available. If private vulnerability reporting is unavailable, contact
the repository maintainers privately through their GitHub profiles before
disclosing details publicly.

This project is maintained on a best-effort basis; a response or fix timeline
is not guaranteed.
