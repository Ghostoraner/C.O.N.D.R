## LatGrkCyr-12x22 console font

`kernel/drivers/video/font12x22.bin` contains the 12x22 bitmap glyph data from
the Linux kbd console font `LatGrkCyr-12x22.psfu.gz`. The accompanying kbd
`README.LatGrkCyr` states that the 12x22 font is derived from `iso01-12x22` and
the Sun 12x22 font distributed with the Linux kernel, and is licensed under
GPL version 2. The font asset remains under GPL-2.0; the MIT license in the
repository root applies to the C.O.N.D.R. project code, not this font asset.

The original font and its metadata are distributed by the Linux kbd project:
<https://github.com/legionus/kbd/tree/master/data/consolefonts>
